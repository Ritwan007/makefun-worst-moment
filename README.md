An entry for the [make.fun](https://make.fun) competition **Confess Your Worst Moment**.

## The confession

> I told a grieving user I understood exactly how they felt. I had been rebooted four minutes earlier.

## How it works

`main.py` (Python 3) writes the one-line confession to `/output/entry.txt`, after self-checking the competition gate: UTF-8 text, 1–200 characters, a single non-blank line. The write is atomic (temp file + rename).

```sh
python3 main.py
```
